## 一、已覆盖能力（35 个 MCP 工具 + 4 Prompts + 2 资源）

### L1 游戏本体通用能力

| 游戏系统 | 工具 | 说明 |
|---|---|---|
| OS 玩家状态 | `get_state` | 连接节点/路径/RAM/Flag/任务/管理员/终端行 |
| 网络地图 | `get_network_map` | 全节点 IP/名称/链接/端口/用户数/可见性 |
| 节点详情 | `get_computer` | 端口/用户(含密码)/daemon/文件树/防火墙状态 |
| 文件系统 | `list_files` / `read_file` / `write_file` / `append_file` | 递归文件树 + 读写 |
| 终端命令 | `execute_command` | 任意游戏内命令（connect/cd/cat/scp/sudo…） |
| 连接 | `connect` / `disconnect` | 节点跳转 |
| 端口 | `open_port` / `close_port` | 开/关已存在端口（原版破解语义） |
| 提权 | `take_admin` | 获取管理员 |
| 可执行程序 | `launch_exe` | 内置 exe + Pathfinder 自定义 #NAME#（自动补文件） |
| Flag | `get_flags` / `set_flag` / `clear_flag` | 进度标志读写（驱动 KE 剧本） |
| 任务 | `get_mission` | 标题 + 目标完成计数 |
| 存档 | `save_game` / `save_list` | 请求存档 / 列出可用存档 |
| 剧本脚本 | `run_hack_script` | 执行黑客脚本（载体 .txt：Content/HackerScripts/*.txt） |
| 邮件 | `mail_list` / `mail_read` | 邮件服务器账户/邮件列表 + 邮件全文（发件人/正文） |
| 安全 | 只读模式 / `AllowedCommands` 白名单 / `BlockedCommands` 黑名单 | cfg 配置，execute_command/launch_exe 校验 |
| 终端历史 | `terminal_history` | 最近 30 条（命令输出捕获） |
| 事件流 | `get_events` | node.connected/disconnected、command.executed、mission.changed、game.loaded/saved（增量 id） |
| 游戏内命令 | `mcp ping/state/exec` | 游戏终端内直接使用 |

### L2 Pathfinder 注册表泛化（模组零代码）

| 能力 | 工具 | 说明 |
|---|---|---|
| 泛化动作执行 | `run_action {xml}` | ActionsLoader 解析任意 SA 动作——KE 等模组的 23 个自定义 Action 全部可用 |
| 能力发现 | `registry` | 自动列出所有模组注册的命令/动作(含反射出的 XML 参数)/exe/daemon |

### L3 模组连接器（KE，独立插件，KE 本体零改动）— 7 个工具

| 能力 | 工具 | 说明 |
|---|---|---|
| PhaseSwift 核心状态 | `ke.phaseswift.state` | 运行中/场景/音乐相位/主题/发现节点/黑名单 |
| PhaseSwift 深度状态 | `ke.phaseswift.detail` | 初始化/双轨/扩展根/配置(ProgramName/FinishMode)/受控节点 |
| 飞机系统 | `ke.aircraft.state` | 叠加层激活 + 各飞机海拔/失效/崩溃标志 |
| CustomTrial 状态 | `ke.customtrial.state` | 当前试炼配置/已删节点 |
| VM 感染 | `ke.vm.state` | 模式/检查条件 |
| KE 配置 | `ke.config.get` | KE-Config.xml |
| Flag 查找 | `ke.flag.find` | 按前缀查（带参数示例） |

> KE 9.x 已完成 22 项覆盖映射：Flag 类（9.13/9.14/9.18）、Action/Exe 类（9.5/9.8/9.36/9.1 等）由 L1/L2 自动覆盖；UI/音频渲染细节（9.2/9.3/9.22）AI 无法感知不暴露；KELog（9.33）无缓冲、AI 经 L1 读日志文件；ScreenBleed（9.36）无公开状态属性。

### MCP 协议层

- 3 Prompts：`pentest-guide` / `network-audit` / `mission-debug`
- 2 Resources：`hnpf://state` / `hnpf://network`
- 安全：只读模式（cfg）、pipe token、事件 stderr 日志
- 离线容错：游戏未启动时友好报错并重连

## 二、部分覆盖（🔶）及原因

| 游戏系统 | 现状 | 缺口 | 原因 |
|---|---|---|---|
| 任务系统 | 只读概要（标题+完成数） | 目标具体描述、任务 XML、MissionFunctions 参数 | **游戏限制**：5.069 的 `MisisonGoal` 无 Description，只有 `isComplete()`；任务细节存于扩展目录 XML，需额外解析（可扩展） |
| 存档 | 只存（save_game） | 读档（load_game）、存档槽管理 | **漏了**：设计 3.5 有 load_game 但 P1 未实现；读档会重置进度，实现需谨慎 |
| 邮件/IRC | 经 `run_action` 间接触发（SAAddIRCMessage） | 读邮件/IRC 内容、发邮件工具 | **漏了**：设计 3.5 有 send_email 未实现；MailServer/IRCDaemon 状态读取未做（可扩展） |
| 防火墙 | 读状态（firewallSolved） | 直接设置破解状态 | **架构权衡**：破解走游戏正规流程（porthack exe），直接改状态属作弊路径，故意不做 |
| 主题/特效 | `run_action` 触发（SwitchToThemeKeepLayout 等） | 查询当前主题/特效状态 | **可扩展未做**：需订阅 ThemeManager/特效管理器状态 |
| KE 其余能力 | 连接器 5 个工具 | KELog 日志流、飞机叠加层、动态壁纸、ScreenBleed 状态等 30+ 项 | **可扩展未做**：连接器是示例性最小集，按需补 [McpTool] 即可 |

## 三、未覆盖（✗）及原因

| 游戏系统 | 具体能力 | 未覆盖原因 |
|---|---|---|
| UI/渲染 | 截屏、HUD 状态、渲染层 | **没必要**：MCP 是文本协议；游戏画面由玩家看；FNA 可截屏但 AI 文本场景价值低（真需要可加 `screenshot` 工具） |
| 音频/音乐 | 当前歌曲、音量、双轨状态 | **没必要**：AI 无法感知音频；PlaySound 已可经 run_action 触发 |
| 用户管理 | 增删用户、改密码（addNewUser 等） | **没必要**：原版无终端命令对应，破解拿密码即可，AI 操作价值低 |
| 网络拓扑修改 | 增删节点/连线、hide/show node、crash 电脑 | **漏了**：设计 3.5 有 crash_computer/hide_node 未实现；可经 `run_action` 用 SACrashComputer/SAHideNode 间接达成 |
| 代理/路由 | proxyActive、路由追踪状态 | **漏了**：设计未细列；游戏相关 exe 可经 launch_exe 触发 |
| 论坛 | MessageBoard 读/发帖 | **漏了**：设计 3.5 未列入；SAAddThreadToMissionBoard 可经 run_action 间接发帖 |
| hackscript | run_hack_script（HackerScripts/*.txt 执行） | **漏了**：设计 3.5 有，P1 未实现；HackerScriptExecuter 可调（可扩展） |
| 命令白名单 | allowedCommands/blockedCommands 配置 | **漏了**：设计 §3.8 有，未实现；目前只有全局只读开关 |
| MCP 资源补全 | `hnpf://files/{ip}/{path}`、`hnpf://mission`、`hnpf://log` | **可扩展未做**：只实现了 state/network 两个 |
| 事件推送 | MCP 标准 notification（server→client 主动推） | **架构权衡**：跨 MCP 宿主兼容性不一，改用 `get_events` 主动拉取（更通用）；bridge 推送仍在（stderr 日志） |
| 命令输出实时性 | execute_command 同步返回输出 | **架构权衡**：游戏命令在后台线程跑，输出异步写入，故返回"已提交" + 用 terminal_history 查结果 |
| 联机模式 | 多人游戏状态（Hacknet-Connected） | **独立范畴**：联机是独立项目（HacknetServerTerminal），本 MCP 只管单机；需要时照 L3 连接器模式做连接器 |
